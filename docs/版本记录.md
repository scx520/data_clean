# 版本记录

## V1.0.0 功能补充 — 2026-10-30

- 数据集卡片新增删除按钮、确认窗口和关联任务数量提示。
- 新增回收站与恢复入口，保留原始内容、历史任务、报告和清洗结果。
- 删除选中数据后自动切换其他数据；删除最后一个数据集后显示空工作台。
- 正在执行的任务阻止删除；已删除数据集需恢复后才可继续清洗。
- 支持旧数据库自动添加回收站字段，无需重新导入。

## V1.0.0 — 2026-10-29

- 界面采用移动蓝（#0085D0）主色，统一菜单、按钮、规则配置、图标和质量报告的蓝白视觉。
- 修复大表预览把前 200 条展示记录误标为总数的问题；预览结果、变更与异常均支持完整分页和搜索。
- 预览明确显示处理前后行数、移除数量、修改单元格数及实际执行字段；强化规则启用和字段选择提示。
- 实现本地通用表格数据清洗平台的首个可运行版本。
- 提供清洗工作台、数据集管理、任务记录、规则模板、质量报告五个功能入口。
- 支持 CSV / Excel 导入与 7 类可配置清洗规则。
- 支持规则启停、排序、预览、后台执行、变更追溯和异常记录。
- 支持结果、变更、异常和质量报告导出。
- 提供 Windows 启动脚本、模拟数据、操作说明和系统设计说明。
- 提供后端自动化测试和浏览器操作测试。
