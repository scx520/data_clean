# 版本记录

## V1.0.0 — 2026-10-29

- 界面采用移动蓝（#0085D0）主色，统一菜单、按钮、规则配置、图标和质量报告的蓝白视觉。
- 实现本地通用表格数据清洗平台的首个可运行版本。
- 提供清洗工作台、数据集管理、任务记录、规则模板、质量报告五个功能入口。
- 支持 CSV / Excel 导入与 7 类可配置清洗规则。
- 支持规则启停、排序、预览、后台执行、变更追溯和异常记录。
- 支持结果、变更、异常和质量报告导出。
- 提供 Windows 启动脚本、模拟数据、操作说明和系统设计说明。
- 提供后端自动化测试和浏览器操作测试。
