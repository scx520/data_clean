# 通用数据清洗平台 V1.0 使用说明

## 1. 软件简介

本软件用于对 CSV 与 Excel 表格进行规则化清洗和质量检查。用户可以在浏览器中导入数据、配置规则、对比结果，并保存清洗任务、复用规则模板、导出处理结果。第一版为本地单工作空间应用。

界面包含左侧功能菜单、中间数据表格预览和右侧规则配置面板。菜单包括清洗工作台、数据集管理、任务记录、规则模板、质量报告。

## 2. 安装与启动

安装 Python 3.12 或更高版本、Node.js 22.12 或更高版本（建议 24 LTS）。在软件根目录双击 `start.bat`，或在 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

首次运行需要网络下载开发依赖。服务启动后，在浏览器打开 `http://127.0.0.1:8000`。启动窗口保持运行；停止时按 Ctrl+C。

## 3. 导入数据

1. 点击页面右上方「导入数据」。
2. 点击上传区域选择文件，或把文件拖到上传区域。
3. 确认文件名，点击「导入并预览」。
4. 软件自动切换至工作台，展示前 50 条记录和质量统计。

支持 `.csv` 和 `.xlsx`，单文件最大 20 MB，最多 100,000 行、200 列。表格第一行为字段名，不能为空或重名。Excel 默认读取第一个工作表。CSV 支持 UTF-8 和 GB18030 编码，忽略全空白行。

首次运行有一个名为「客户信息示例（模拟数据）.csv」的数据集，包含 52 条人工生成记录，可直接用于体验和演示。

## 4. 查看原始数据

通过「当前数据集」下拉框切换数据。表格支持左右与上下滚动、每页 50 条分页、关键词搜索。原始行号在导入时生成，后续清洗和变更记录继续引用该编号。

空值以浅黄色「空值」标记显示。页面顶部展示记录数、缺失单元格、整行重复记录和完整性评分。原始视图的统计对应导入内容；清洗视图对应处理结果。

### 删除与恢复数据集

在「数据集管理」中，每张数据集卡片右下方都有「删除」按钮。点击后弹出确认窗口，列出数据集名称、行列数量和关联任务数量。点击「取消」保留数据集；点击「确认删除」将其移入回收站。

进入「回收站」页签，点击「恢复」，数据集重新出现在全部数据集列表和工作台选择框中。此操作不清空原始内容、不删除关联历史任务或清洗结果，也不释放原始数据占用的磁盘空间。本版尚未提供永久删除。

删除当前选中的数据集后，工作台自动选择其他可用数据；没有其他数据时显示导入空状态。任务执行期间不能删除对应数据集。已删除数据集的历史任务仍可查看结果、原始数据、变更、异常以及导出；恢复数据集后才能发起新的预览和清洗。

## 5. 配置清洗规则

点击右侧卡片展开配置，点击字段标签选择处理字段。使用开关启停规则，使用上下箭头调整顺序，使用删除按钮移除规则。规则严格按从上到下的顺序执行，每个任务最多 30 条规则。

字段较多时，可在字段区域搜索名称，例如输入「客户」查找客户编号、客户姓名、客户经理。点击「全选」「清空选择」「反选」可批量操作；搜索状态下按钮变为「全选匹配项」「清空匹配项」「反选匹配项」，仅改变匹配字段，保留其他已选项。清除搜索会重新显示全部字段，不会改变选择。下方实时显示已选数量，字段标签区支持滚动。

去空格和去重规则保持「不单独指定字段时使用全部字段」的含义，清空后界面会显示实际处理范围。其他规则清空后需重新选择字段。聚类最多选择 20 个字段，超过时提示并保留原有选择。

| 规则 | 配置 | 处理方式 |
| --- | --- | --- |
| 去除首尾空格 | 可选字段，不选表示全部字段 | 删除文本两端空格、换行、制表符 |
| 填充缺失值 | 至少一个字段，非空填充内容 | 将空或仅含空白的值替换为指定内容 |
| 去除重复记录 | 可选判重字段，不选表示全部字段 | 内容完全一致时保留第一条记录 |
| 文本替换 | 字段、查找内容、替换内容 | 文本逐字匹配替换；替换内容可为空 |
| 统一英文大小写 | 字段、大写或小写 | 转换英文字符大小写 |
| 转换字段格式 | 字段、日期或数值 | 日期输出 YYYY-MM-DD；数值去千分位并统一表示 |
| 标记异常数据 | 字段、手机号或邮箱 | 检查格式，将不符合格式的值记录为异常 |
| 聚类分析 | 分析字段、数值 / 中文文本、2–12 组、新字段名称 | 按相似特征分组，新增标签并生成分组概况 |

去重规则会受到之前规则的影响，例如先去空格，再按姓名去重。转换失败保留原值，并将原因列入异常记录；格式校验只标记，不修改数据。

规则参数、字段、顺序、启停状态发生变化时，当前预览或结果视图会失效并切回原始数据，以免误用过期结果。已保存历史任务不受影响。

### AI 聚类分析

1. 点击「添加清洗规则」，选择「聚类分析」。
2. 选择 1–20 个分析字段。金额、次数、时长等选择「数值聚类」；企业名称、业务备注等选择「中文文本聚类」。编号、手机号通常不适合作为数值相似度依据。
3. 设置 2–12 个分组，以及新增列名称（默认「聚类分组」）。名称不能与已有字段重名。
4. 点击「预览效果」。表格新增分组列，分组概况展示参与 / 未参与数量、各组人数和占比，数值组展示字段均值，文本组展示文字特征及示例。
5. 确认后执行清洗。标签随 Excel / CSV 一起导出，分组概况保存在历史任务与质量报告中，也包含在 JSON 报告中。

数值聚类会自动平衡字段量纲，跳过空值、非数值、无穷大及绝对值超过 1e100 的记录；文本聚类每字段取前 512 字，空文本不参与。不参与的记录仍保留，标签为「未参与」，原因列在异常记录中。有效记录数或不同特征数少于分组数量时会提示调整，不会强行生成分组。

本功能是本地无监督机器学习，不调用云端大模型，无需密钥。中文文本按文字片段相似度归组，不代表业务语义一致。分组编号仅作标识，不代表好坏或等级。分组概况对应此规则执行时的数据，后续规则可能继续变更 / 去重；建议先完成清洗，再执行聚类。新增标签以独立的「新增标签」数量显示，不参与原始字段完整性评分。

## 6. 预览和执行

点击「预览效果」，软件对完整数据应用启用规则，展示质量统计及清洗预览。可切换「原始数据」「清洗预览」「变更记录」，启用校验且发现异常时还会出现「异常」页签。

预览会显示「原始行数 → 预览结果行数」「移除行数」「修改单元格数」。表格每页显示 50 条，底部总数对应全部预览结果，不是本页条数；预览结果、变更和异常都支持完整分页与全量搜索。

展开「本次实际执行」可核对实际参与处理的规则与字段，以及各规则产生的变更、移除行数和异常数。没有产生变更时，会额外提示核对实际字段。去重规则不选择字段表示按全部字段联合判重；只选择「客户经理」时，每个客户经理仅保留第一次出现的记录，即使其他字段内容不同。

预览临时缓存保留 24 小时，过期后重新点击「预览效果」即可；正式执行后保存的任务结果不受预览过期影响。

确认效果后点击「执行清洗」。任务在后台执行，状态自动更新。完成后保存任务、完整结果、变更和异常记录，按钮区域出现「查看质量报告」「导出结果」。原始数据不会被覆盖。

## 7. 检查与导出

变更记录包含原始行号、字段、原值、新值、使用规则与操作类型。重复行删除以整行变更表示。异常记录包含原始行号、字段、异常值、规则与原因。

「导出结果」菜单支持：

- 清洗结果：Excel 或 CSV。
- 变更记录：CSV。
- 异常记录：CSV。

CSV 使用 UTF-8 BOM，便于 Excel 识别中文。为防止电子表格将文本当成公式，导出时对以公式符号开头的文本加转义前缀。

## 8. 模板、任务与报告

**规则模板**：在工作台点击「存为模板」，填写名称和可选说明。进入模板页点击「应用到工作台」，即可复用字段、参数和执行顺序。目标数据缺少模板要求的字段时，系统会提示，不会自动套用。模板可删除。

**任务记录**：展示任务名称、数据集、状态、规则数、处理结果与创建时间。完成任务可点击「查看结果」，重新打开结果、变更和异常视图。失败任务展示错误提示。

**质量报告**：选择已完成任务，查看清洗前后记录、缺失、重复、完整性评分、各字段完整率和规则处理数量。可下载 JSON 格式报告，或回到结果视图查看明细。

评分公式：`max(0, 100 × [1 − (缺失单元格数 + 整行重复数 × 字段数) / 总单元格数])`。没有数据时计为 100 分。评分只反映缺失和整行重复；格式异常单独统计，且取决于启用的规则，不代表业务内容已完全准确。

## 9. 数据保留和常见问题

- 本地 `.data` 目录保存 SQLite 元数据、原始记录与任务结果，升级软件时请保留并备份整个目录。数据不会同步到 Git 仓库。
- 关闭服务后页面无法继续操作，重新运行启动脚本即可恢复。正在执行时重启服务，任务会标为失败，可重新执行。
- 导入失败时检查扩展名、大小、表头重名 / 空白以及 CSV 列数是否一致。
- 标识编号请在 Excel 中以文本保存。仅通过数字显示格式补零的编号，导入时无法恢复显示用的前导零。
- 日期如存在月 / 日顺序歧义，建议先统一为 YYYY-MM-DD。
- 第一版默认只允许本机访问，不包含登录鉴权、多人权限和多工作空间功能。
